常见问题

你可能想问的

免费版有什么限制？+
Free 套餐最多 5 名成员、3 个项目，包含基础看板与文档功能，适合个人或刚起步的小团队。需要更多容量可随时升级。
可以随时取消吗？+
可以。订阅按月计费，随时取消，取消后当前周期内仍可使用，到期自动降级为 Free。
数据安全吗？+
所有数据加密传输与存储，Team 套餐提供 SSO、权限分级与审计日志。我们通过 SOC 2 Type II 合规认证。
支持从其他工具迁移吗？+
支持。我们提供从 Trello、Asana、Jira、飞书等平台的一键导入工具，迁移过程保留任务、成员与历史记录。
有 API 可以对接内部系统吗？+
有完整的 REST API 与 Webhook，Pro 及以上套餐可用。文档详见 developers.flowbase.io（演示链接）。
